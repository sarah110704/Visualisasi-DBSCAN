DBSCAN Clustering Visualizer

Cara menjalankan:
1. Extract file ZIP.
2. Buka folder dbscan-visualizer.
3. Klik dua kali file index.html.
4. Klik tombol Data contoh.
5. Klik Step berikutnya untuk melihat proses satu per satu, atau klik Jalankan otomatis.

Isi fitur:
- Visualisasi titik data.
- Radius eps untuk mencari tetangga.
- MinPts sebagai syarat kepadatan.
- Cluster berwarna.
- Noise berwarna merah.
- Penjelasan step-by-step.

Catatan:
DBSCAN mengelompokkan data berdasarkan kepadatan. Berbeda dari K-Means, DBSCAN tidak perlu menentukan jumlah cluster dari awal dan bisa mendeteksi noise.
